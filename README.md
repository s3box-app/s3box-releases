# S3Box

A local S3 server for your Mac. Start it from the menu bar, point your app at it, and store files on your own disk.

- S3-compatible endpoint on `localhost`
- Accounts, buckets, and a built-in file browser
- MCP server, so Claude can list, upload, and read files
- Updates itself

## Download

Get the latest `S3Box-x.y.z.dmg` from [Releases](../../releases/latest). Open it and drag S3Box to Applications.

Requires macOS 14 or later. Apple silicon and Intel.
